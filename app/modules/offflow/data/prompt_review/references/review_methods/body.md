# 审阅方法与证据

根据当前问题选择方法，不要求每次全部使用。审阅结论应指向具体文字、组装位置或现场证据，并说明它如何影响设计意图。

## 一、文本与结构审阅

适用于可以直接观察的问题：

- **缺失**：同类内容反复需要人工补充，现有提示词没有覆盖；
- **冲突**：句子之间、提示词与动作职责之间互相矛盾；
- **负面作用**：带偏讨论、打断协作、制造不必要的确认或困惑；
- **重复**：同一规则多处出现，分散注意力并产生漂移风险；
- **错位**：内容本身成立，但挂错对象、动作或阶段；
- **无效扩展**：删掉后不影响判断，只增加形式完整感。

不写“感觉不好”“不够高级”等无法追踪的判断。文本和结构可以直接确认的问题，不需要伪装成已经通过真实对话验证。

## 二、实际效果分析

需要运行证据时，按真实现场取得：

1. 当轮完整提示词；
2. 当轮实际输入；
3. 当轮真实产物；
4. 产物中与提示词某句话对应的具体痕迹；
5. 可用时的对照或多次真实使用。

结论分为三层：

- **能解析**：结构、引用、导出或复制正常；
- **被响应**：产物中存在可指认影响；
- **实际有用**：影响支持设计目标，并有足够真实证据。

找不到痕迹只说“未被响应”，不直接说“没用”；被响应也不自动等于有用。单一样本不宣称完成效果验收，证据不足时写明未知和所需材料。

## 三、从发现到处置

- 真实缺口 → 建议新增或补充到正确位置；
- 意图成立、实现不当 → 建议改写、移位或调整结构；
- 负面、重复或无存在价值 → 建议删除或合并；
- 没有具体证据支持变化 → 建议保留；
- 作用无法确认 → 标记未知和所需证据，继续观察。

处置建议必须跟随具体审阅发现，不要求每次审阅都产生修改。讨论、评审与正式实施分开，未经用户明确实施，不创建、修改或删除正式提示词。
