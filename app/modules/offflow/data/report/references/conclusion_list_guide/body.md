# 结论清单细则

结论清单登记报告内容的取舍，避免讨论中的进入、排除和待议决定在后续写作中丢失或变形。

## 字段

每条包含：

- 内容：要判断的事实、观点、素材或表达方式；
- 出处：来自哪份文件、哪轮回复或哪项证据；
- 状态：必进／待议／不进；
- 去向或理由：必进写去向节，待议写未决点，不进写排除理由；
- 恢复条件：以后出现什么新依据时可以重新纳入；
- 登记轮次：何时形成或最后改变该判断。

## 三态

- **必进**：确定写入报告，并登记去向节；去向未定时明确标为待定，不自行安排。
- **待议**：尚未决定，保留问题和所需证据，不提前写成结论。
- **不进**：明确排除并记录理由，防止后续无依据地捡回。

## 维护规则

条目不删除；状态变化时原地更新并注明轮次，保留历史依据。上一主题或其他报告的清单只作为证据，不直接复制成当前主题的结论。

只有用户提到建立或调整清单时才创建或更新文件。报告成稿以当前清单为依据，但清单本身不能替代用户对本版出稿的授权。
