# 报告成品判断细则

检查只列问题、位置和理由，不直接改稿，不替作者辩解。

## 一、结构五问

1. **论点指证**：每节的一句话论点能否指到数据、文件或事实？指不到就降级为待验证或删除。
2. **换序**：相邻两节对调是否更顺？对调后一样顺，说明顺序缺少理由，应重排、合并或删除。
3. **去重**：同一件事是否在别处又说了一遍？保留主要论述位置，其余删除或改成指针。
4. **删段**：删掉任意一段会损失什么？说不清损失的段落就是可删内容。
5. **一句话**：读完第一节能否说出全文主线？不能就说明结论埋得太深。

## 二、事实三查

凡功能、自动化能力、数字和成效结论，都检查：

- **存在性**：功能或事实是否真实存在，有没有代码、页面、文件或用户确认作为依据；
- **可取性**：数字由谁统计、统计时段和口径是什么，能否复核；
- **归因**：成效能否记到当前对象头上，是否存在其他原因或无法归因的情况。

出现“保证、彻底、一定能、自动、智能、AI”等强表述时，必须有证据；没有就改成有限、可验证的表达。

## 三、读者重读

站在目标读者位置，只记录不评价：

- 读到哪一段会停下来？原因是看不懂、不信，还是产生新的问题；
- 读完这节会问什么？下一节是否接住；
- 哪一句像套话、空话或与读者无关的叙述。

输出位置／停下的原因／读者会问什么，用于回到骨架、清单或正文修正。
