**口径说明**

- 总投入（认知+AI）= 各轮 认知时长+AI耗时 合计；轮间间隔 = 本轮起点 − 上一轮完成通知（首轮为 0），原样记不剔除
- 认知时长 = 人思考 + 落在 ≤10min 的轮间间隔（估计值，保守下界）；超过 10min 的间隔不计入，完整轮间间隔仍单列；重建轮无认知时长（恒 0）
- AI执行=同 target 每次发送里第一个不超阈值的候选（无通知记未知，不编造）
- 剔除 = 本轮被放弃的跨度（第一候选 → 采用候选）；输入段 / AI 各一笔、分列记不合并，不计入认知或总投入；降档到底则该段时长记 0
- 剔除次数按段计：输入段 / AI 段各最多 1 次，一轮最多 2 次
- 平均每轮耗时（认知 / AI）：认知仅对讨论轮求平均；AI 对所有 aiSec 非 null 的轮次明细求平均
- 墙钟=首末日志原始跨度
- 人字数=需求.txt+对vN回复.txt；AI字数=vN.md+实施/已实施.md 正文（剥离 front matter）
- 字符数 >=1万 按量级缩写（如 2.05万），精确值见 stats.json
- 重复发送去重：同 target 且配对同一完成通知的重复发送合并为一轮，取第一个不超阈值的候选（明细文件列标注已合并，并带出被合并的执行类次数）
- 多 target 发送：认知时长/轮间间隔/输入段剔除只计入第一个有效文件行，其余记 0；文件不存在且无通知的虚空行不列入明细（全虚空时保留首行记未闭环）
- 百分比分母：总览三列统一为总跨度（可跨列相加：自身+子主题≈总）；自身统计与轮次明细为自身墙钟；无发送记录的孤儿时段不计轮，故百分比合计可能不足 100%
- 重建轮=以 target=上下文重建 的完成通知为起点，向前配最近一次未被占用的 复关系 发送（人思考/认知/字数恒 0，轮间间隔照常，其完成通知参与轮间锚点）；无通知不算一轮；未知轮数=三类发送中无 target 的计数
- 总览三列：总（含子主题）= 自身 + Σ 直接子主题的 aggregate（孙主题已含在子内）；墙钟类仅自身不求和，总跨度取最早创建→最晚活动
