# 实施文档.md 的拆分结果

## 一、拆分说明

**依据**：`实施文档.md` 4.2 的三行表给出三个步骤的名称、输入、形态、产出与验收；4.3 给出顺序与那次复关系的位置；4.5 给出整体验收。拆分以这三节为准，未另行设计。

**为什么这么拆**：

- 一种形态一个子步骤——三步各只有一种形态，演示不串味。
- 顺序按对象成熟度：`01` 把大纲挤干净 → `02` 考干净版本 → `03` 提炼已确认的点。反过来答辩会考到后来被删的内容，演示就成了错误示范。
- `01` 与 `02` 之间那次换会话是真动作：复关系不产文件，所以它不占步骤，只做前置动作，效果落在 `02` 第一轮的题目里。

**依赖链**：`01` →（复关系）→ `02` → `03`。每步都独立可验收，不依赖后面的步骤。

**本次只拆分，不执行**：只建目录与同名文档，不写各步的 `需求.txt`、不跑任何形态。
