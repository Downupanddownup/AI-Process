# v2 — 三个子步骤，一种形态一步

活就是当前这件：把这套演示做出来。所以三个子步骤处理的都是"这套演示本身"——同一份对象，三次不同动作。

## 一、拆分

| 步 | 形态 | 输入 | 产出 | 验收 |
|---|---|---|---|---|
| `01-质检形态` | 质检码 | 先把"演示大纲"（300 字内）立起来，再对它跑质检 | 大纲＋一份清单 | 清单每条给位置与理由；至少两条是"可删／可并"这类可执行改动 |
| `02-答辩形态` | 复盘·答辩 | 01 定稿的大纲 | 3–5 题＋作答＋逐题评价 | 作答时不翻文档；评价逐题给分与依据 |
| `03-技炼形态` | 复盘·技炼 | 同一份大纲 | 2 条技术点 | 每条一句话能复述；不得抄大纲原句 |

## 二、拆分思路

1. **一形态一步**——你定的规则；一步之内只出现一种形态，演示不会串味。
2. **顺序按对象成熟度**：先质检把大纲挤干净，再答辩考它，最后技炼提炼它。反过来，答辩会考到后来被删掉的内容，演示就成了错误示范。
3. **01 承担两件事**：立对象＋质检。没有对象，三个动作全是空转；而对象若先于子步骤产生，就得另设一个"不演示任何形态"的步骤。若你想让它干净，我加一个 `00-立大纲`，但那个步骤演示不了九形态里的任何一个。
4. **结果微调挂在 02 下**（`02/结果微调/01`）：答辩最容易暴露"我理解的和你写的不是一回事"，这比文字问题更值得立案；挂 01 则只是改字，示范价值低。

## 三、九形态在哪一轮出现（证明不缺）

| 形态 | 出现的轮次 |
|---|---|
| 复需求·single | 本主题 v1（这一轮） |
| 复回复·direct | v2、v3……主链 |
| 复回复·实 | 拆分方案定稿那一轮（出实施文档），不占子步骤 |
| 复执行·步目 | 拆出上面三步的那一次 |
| 复执行·改吧 | 各子步骤的执行轮 |
| 质检码·single | `01` |
| 复盘·答辩 | `02` |
| 复盘·技炼 | `03` |
| 复关系·auto | 任意一次换会话后的现场重建 |

## 待确认问题区

### Q1：按这三步拆，还是先加一个 `00-立大纲`？
  推荐按三步：01 里先立大纲再质检，能少一个不演示任何形态的步骤。
